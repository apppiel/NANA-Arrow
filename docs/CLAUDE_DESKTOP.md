## (원문) 디렉터 확인 요청 (2026-09-17, GAME_RULES v0.4 검토)
1. **Key 타입 정의 누락** — LEVEL_FORMAT 에는 Key 가 있는데 §3 표·`ArrowType` 에 없음. 제안: Basic 과 같고 keyGroup 만 가짐, Locked 와 같은 26레벨 도입

4. **§9 "하단 부스터 바"** — §6 에서 부스터 v1 전체 제외와 충돌. 제안: 하단 바 삭제 또는 목숨 표시 위치로 전환
5. **§7 "별 3개 시 보너스"** — §5 별점 v1 미포함과 충돌. 제안: v1 은 `coinPerClear` 만
