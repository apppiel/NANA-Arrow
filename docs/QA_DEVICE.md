# QA_DEVICE.md — 첫 실기 빌드 체크리스트 (20항목)

> 개발 빌드를 폰에 올린 뒤 순서대로 확인한다 (`docs/BUILD.md`). 안 되는 항목은 번호와 함께 프로그래머에게 알려 주면 된다.
> 에디터에서는 정상인데 실기에서만 깨지는 것들을 모았다.

## 실행·화면
1. 앱 아이콘을 눌러 **Boot → Main 으로 자동 전환**된다 (검은 화면에서 멈추지 않음)
2. **세로로 고정**된다 — 폰을 눕혀도 화면이 돌지 않음
3. 노치·펀치홀·하단 제스처 바에 **UI 가 가리지 않는다** (SafeArea)
4. 한글이 **□□□ 로 보이지 않는다** (TMP 폰트)
5. 기종 해상도에서 보드가 화면 밖으로 잘리지 않는다 (잘리면 줌·팬으로 볼 수 있으면 정상 — GAME_RULES v0.7.2 §10)

## 입력
6. 화살표 **탭**이 한 번에 인식된다 (두 번 눌러야 하거나 씹히지 않음)
7. **길게 누르기**로 레인 미리보기가 뜨고, 떼면 사라진다
8. **한 손가락 드래그**로 보드가 움직인다. 드래그한 터치는 **탭으로 세지 않는다** (하트가 줄지 않음)
9. **두 손가락 핀치**로 확대·축소된다 (기본 1.0, 0.5 까지 축소 / 3.0 까지 확대)
10. **빈 곳 더블 탭**으로 줌이 원래대로 돌아온다
11. 우하단 **`#` 격자 토글**이 켜지고 꺼지며, 앱을 껐다 켜도 상태가 유지된다

## 게임 흐름
12. 레벨 클리어 → 클리어 팝업 → **다음 레벨**로 이어진다
13. 하트 0 → 실패 팝업 → **이어하기(광고)** → 하트가 차고 보드는 그대로
14. 실패 팝업 **다시하기** → 레벨이 처음부터
15. **Android 뒤로가기 버튼**: 팝업이 열려 있으면 팝업만 닫히고, 게임 화면에서는 메인 확인 팝업이 뜬다 (앱이 바로 종료되지 않음)

## 저장·설정
16. 레벨을 깨고 **앱을 완전히 종료 후 다시 실행**해도 진행도가 남아 있다
17. Main 의 설정에서 **사운드·진동** 토글이 저장된다
18. **하트가 줄 때만 진동**한다 (다른 동작에서는 진동 없음)

## 광고·성능
19. 광고가 **테스트 광고**로 뜬다 (실제 광고가 뜨면 즉시 중단하고 알릴 것 — 정책 위반)
20. 30분 정도 이어서 플레이해도 **발열·끊김·강제 종료**가 없다
